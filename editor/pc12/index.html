    Web-MIDI editor for the Faderfox PC12. Built on the PC4 editor by Peter Witzel (faderfox-editor, MIT) via the lsim fork. Sysex format notes and a command line tool live in pc12.py next to this folder.

    Privacy: everything stays in this browser. Setups are kept in localStorage so a reload does not lose them.
